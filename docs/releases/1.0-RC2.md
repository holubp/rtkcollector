# RtkCollector 1.0-RC2

Release date: 2026-07-27

This release candidate includes the tagged source and
`rtkcollector-v1.0-RC2-debug.apk` for direct testing. The APK identifies itself
as `org.rtkcollector.app` version `1.0-RC2` (version code 2), includes
`arm64-v8a` and `armeabi-v7a`, and has SHA-256:

`7e11667d1f7299e5b6536937b7f5f8f4dbb6da2d7250d56b5bc31ed1579d83e8`

The APK is signed with an Android debug certificate. It is suitable for
side-loaded testing, but it is not a production-signed Google Play artifact.
No release AAB is included.

## Highlights

- The Home dashboard now has a `Sessions` shortcut that opens the existing
  recent-sessions and sharing screen while preserving origin-aware Back
  navigation and the existing active-session, archive, lease and sharing
  protections.
- NTRIP shutdown during a reconnect delay now completes as intentional
  cancellation without surfacing an interruption warning as an app error.
- Byte-exact receiver capture remains authoritative and isolated from UI,
  parser, NTRIP, quality-monitor and RTKLIB failures. Receiver RX, app TX,
  correction input, events, quality and metadata remain separate artifacts;
  session metadata does not contain raw NTRIP credentials.
- Existing receiver control, NTRIP correction routing, temporary-base and
  fixed-base workflows remain available for the supported receiver families.

## Important Limitations

- RtkCollector targets external USB GNSS receivers; it is not a phone's
  internal-GNSS application.
- UM980 and u-blox M8T are the primary tested receiver families. M8P and F9P
  may work through compatible u-blox modes, but precise positioning has not
  been validated by the author on those devices.
- NTRIP profiles currently permit cleartext TCP. Credentials, GGA positions
  and correction/source data are not encrypted unless the selected external
  service provides separately secured transport.
- This remains release-candidate software. Validate recorded raw data and
  derived positions before operational or safety-relevant use.

## Release Gates

Before Google Play publication, the project still requires a signed release AAB,
release-bundle native-library verification, Android permission and
foreground-service checks, installation on Android 13 or newer, and the manual
recording, NTRIP, session-sharing and settings-backup checks in
`docs/play-publication.md`.
