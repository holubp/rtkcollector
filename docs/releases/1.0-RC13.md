# RtkCollector 1.0-RC13

Version code: 14. This is a new release candidate, not a replacement of RC12.

## Changes

- Restore visible blue rover and yellow base satellite bars on narrow main
  monitoring cards. Individual box outlines are omitted when they would cover
  the colored interior; gaps and the frequency-cell outline remain visible.
- Reflow frequency groups into fewer columns only when even borderless boxes
  would be too thin. Label measurements include current text size and density.
- Preserve used/visible counts, colors, the selected solution engine and the
  detailed satellite-monitor screen. Receiver, NTRIP and raw recording paths
  are unchanged by this rendering fix.

The rendering fix is `c0bf89b22fb83d03aa36a22ec3602bf4dac072d9`. Its independent
review found no blockers; 17 focused model tests include 75 width/font/density
cases. The full local gate passed 1512 JVM tests with no failures/errors/skips,
and [clean-host CI](https://github.com/holubp/rtkcollector/actions/runs/41978998552)
passed both distributions, native checks, release lint, assembly and signing
smoke checks before release packaging.

## Artifacts And Updating

The [GitHub prerelease](https://github.com/holubp/rtkcollector/releases/tag/v1.0-RC13)
is the publication record for the exact source tag, release-candidate CI,
stable-signed APK, checksum and signing receipt. Source ZIP/tar downloads belong
to the same immutable tag. The source tag must not be moved to later
documentation commits.

- Package: `org.rtkcollector.app`.
- Version: `1.0-RC13`, code `14`.
- Native ABIs: `armeabi-v7a` and `arm64-v8a`.
- Stable signing certificate SHA-256, unchanged from RC12:
  `d8047f43b2748198ae69ff773be13d3aa11c8ac36159dd4e6768a3ac2db3e329`.

Use the stable-signed sideload APK for an existing stable-key installation.
Do not uninstall a matching-key installation merely to update it: app-owned
settings and recordings can be lost on uninstall. Installations signed with
another key, including a Windows debug key, are a separate compatibility case;
see [stable sideload signing](../sideload-signing.md).

## Validation Boundaries

Width-budget tests, compilation, host CI and signature checks do not establish
physical-phone appearance or an actual in-place update. Check the compact
satellite card in light/dark styles, portrait/landscape and larger system fonts,
and compare its positive counts with the detailed screen. Colored interiors,
readable counts and box gaps should remain visible. No new device/USB/audio or
field validation is claimed for this release.
