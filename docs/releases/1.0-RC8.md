# RtkCollector 1.0-RC8

## Changes

- Minimal logging is always enabled for session lifecycle and stop evidence.
- Verbose and Debug logging are cumulative, persist across app restarts and
  show a compact main-screen advisory linking to logging settings.
- Optional logs start with a configurable 10 MB cap and seven-day retention;
  performance monitoring remains independent.
- Session summaries distinguish initiating stop reasons, close failures and
  incomplete evidence without guessing why Android stopped an earlier session.
- Essential logging uses an isolated bounded writer. A stalled diagnostic tail
  cannot retain raw files or prevent a new recording after other writers close;
  the old session remains protected from sharing/deletion until that tail ends.
- App log sharing sanitizes legacy retained records, checks free space and
  protects shared ZIP copies for one hour (maximum three copies).
