# RtkCollector 1.0-RC5

RC5 makes fixed settings-set options consistent between the main screen and
recording start. A fixed Home selector is greyed out and marked with a lock;
Start uses the same value shown there, even when an older local override is
stored. Changeable workflow selections remain in effect when Start is pressed.
The settings-set editor exposes fixed-option switches for supported profile
selectors, and a fixed base-coordinate choice cannot be changed through the
coordinate picker.

RC5 is a sideload debug testing build. Its APK must be signed with the same
stable certificate as the re-released RC4 APK to support in-place updates.
The GitHub release workflow verifies the pinned certificate and publishes a
checksum and signing receipt. Google Play packaging and publication are
separate; this release does not claim Play readiness.

Manual device checks remain: inspect fixed controls in compact and rail
layouts, verify a changeable workflow remains selected after restarting the
app, and confirm an installed stable-key RC4 APK updates to RC5 without
uninstalling.
