# RtkCollector 1.0-RC3

Release date: 2026-09-25 (re-release; original source release 2026-09-24)

This source release identifies the Android app as `org.rtkcollector.app`
version `1.0-RC3` (version code 3). The GitHub release includes a debug-signed
sideload testing APK and SHA-256 file built from this exact tag. It is not a
Google Play artifact. The Google Play artifact must be built and upload-signed
from this exact tag on the Windows Android Studio host.

## Highlights

- NTRIP correction download, sourcetable access and base source upload now use
  TLS with Android system trust and hostname verification in the Google Play
  distribution. Plaintext and explicitly acknowledged unsafe TLS remain
  sideload-only compatibility options.
- TLS profile validation occurs before socket construction and again at the
  recording-service boundary. Failed TLS handshakes do not fall back to
  plaintext, and diagnostics redact credentials and transport material.
- The Home dashboard retains the direct `Sessions` shortcut added in RC2, and
  RC2 source changes are included in this candidate.
- Settings backups exported by RC2 with plaintext passwords now restore the
  historic caster-password reference when it exactly matches an imported
  caster profile. The password is re-keyed to a fresh RC3 secret reference;
  unrelated password entries remain rejected.
- Byte-exact receiver capture remains independent from correction, parser,
  UI, RTKLIB and caster-upload failures.

## Remaining Release Gates

- Build and inspect an upload-signed `googlePlayRelease` AAB on Windows using
  the procedure in `GPLAY.md` and `docs/play-publication.md`.
- Perform real TLS correction-download and source-upload tests with the target
  casters and attached receiver hardware.
- Complete Play Console declarations and the Android notification, Files/share
  and field-workflow checks listed in `docs/play-publication.md`.
