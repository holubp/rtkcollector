# RtkCollector 1.0-RC7

RC7 adds a `Fix it` button to the battery-optimisation warning, in both compact
and rail dashboard layouts. It opens Android's battery-optimisation settings,
falling back to RtkCollector's app-details settings if the first screen cannot
be opened. If neither is available, the app explains how to open settings
manually rather than crash.

Returning to the app refreshes its standard optimisation-exemption check and
hides the warning when exempt. The button does not change power settings,
request an exemption automatically, or start/stop recording. The warning's
existing idle-only visibility is unchanged. Manufacturer-specific background
restrictions may require additional manual settings.

The package remains `org.rtkcollector.app`, version name `1.0-RC7`, version code
`8`. The GitHub APK is signed with the same pinned stable sideload certificate
as RC6 so Android can update an installed stable-key build without uninstalling
it. This is a sideload debug prerelease, not a Google Play publication.

The bounded change received a focused independent review with no blocking
findings. Its pure settings-launch/fallback policy has regression tests;
Android intent resolution, manufacturer settings, return refresh, Activity
recreation and compact/rail visual checks remain pending device validation.
RC6 settings-ownership validation gaps also remain pending; see the RC6 notes.

## Release Gates

The owner requested this follow-up as the next GitHub RC while strict
specification-framework integration remains deferred until after validation.
This release uses the reviewed checked-in validation gates. It does not claim
that the separate, uncommitted strict assurance framework has passed or waive
that framework permanently. Full-host CI and stable signing verification are
required before publishing the APK.

The GitHub release includes the APK, SHA-256 checksum and signing receipt. Its
receipt identifies the exact compiled source and signing-tooling commits;
those release assets and workflow results are authoritative artifact evidence.
